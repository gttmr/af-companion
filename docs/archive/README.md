# Archive

이 디렉터리는 활성 기준이 아니다.

`docs/archive/**` 문서는 과거 계획, 리뷰 기록, 스캐폴딩 노트, 스킬 노트, 유지보수 프롬프트를 보존하기 위한 자료다.
현재 taxonomy, schema, validator, analyzer prompt 판단 기준은 다음 파일을 따른다.

- `README.md`
- `AGENTS.md`
- `CLAUDE.md`
- `docs/README.md`
- `docs/workbench/*.md`
- `packages/web/src/analyzer/types.ts`
- `schemas/*.schema.json`
- `scripts/validate-artifacts.mjs`

archive 문서의 예전 `workflow_kind`, process-flow shape, ADK 1.x workflow-agent 표현은 현재 계약을 override하지 않는다.
