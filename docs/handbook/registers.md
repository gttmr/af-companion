## 해석 원칙

Register ID는 Handbook 내부의 안정 식별자다. Current Implementation은 strict Target `contract_version: "2.0"`만 읽고 쓰며 removed root/field를 변환하지 않는다. Asset category, Graph envelope, invocation control과 A2A protocol 의미는 [Taxonomy](../workbench/taxonomy.md)와 [Graph IR](../workbench/graph-ir.md)의 Target Contract를 따른다.

CLI Companion의 네 Register는 Interaction state와 connector capability다. 일반 workspace snapshot, source projection, git projection, evidence projection Register를 active로 두지 않는다. 그런 observer는 아직 구현되지 않았다.
