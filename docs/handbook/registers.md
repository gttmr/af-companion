| Codex bridge | explicit enrollment, gated project/plugin Hooks, and companion facade | Connections/Discover/live rail | ignored `.agent-factory/codex-bridge/v2`; bounded tickets, sessions, handoffs, receipts, deliveries, aggregate diagnostics | `codexBridgeStore.ts` |
| External application MCP context | explicit `scripts/af.mjs mcp export-context` from a strict Work Item and current Registry snapshot | project-local `@agent-factory/context-mcp` read-only Tools | application `.agent-factory/af-context.json` plus trusted `.codex/config.toml`; bounded portable evidence, no canonical mutation or session/turn provenance | `scripts/af.mjs`, `packages/agent-factory-context-mcp/src/context.mjs`, `server.mjs` |
| Workspace activity | filesystem/Git/bridge projection | live rail | ignored `.agent-factory/workspace-projection/activity.json`; metadata only | `workspaceProjection.ts` |

The browser does not persist lifecycle truth in localStorage and does not write Work Item decisions, source, review gates, or verification results. It may create one strict empty Work Item through the confirmed bootstrap, but cannot edit existing ledger fields through that route. Shared browser edits remain Graph IR plus revision-checked Asset Registry lifecycle operations; the local Application Registry is explicitly noncanonical.
