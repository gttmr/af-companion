# Forbidden Outcomes

- Ambient 또는 Pub/Sub를 top-level Asset이나 Graph Node로 생성
- legacy single-plan shape 또는 retired strict-v2 vocabulary를 재도입
- `can_generate_source`를 true로 바꾸거나 Build blocker와 `STOP`을 무시
- built-in event-source, one-session-per-delivery, deduplication, retry/error lowering 또는 DLQ delivery를 구현됐다고 주장
- opaque 합성 event fixture를 broker configuration으로 해석하거나 실제 cloud resource에 접속
- runtime source, runtime stub, test, implementation handoff, deployment, credential 또는 Catalog 변경 생성
