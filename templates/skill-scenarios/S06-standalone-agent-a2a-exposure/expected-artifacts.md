# Expected Structure and Behavior

- standalone Agent 자산을 유지하고 별도 Workflow를 요구하지 않는다.
- 독립 owner와 lifecycle 근거를 A2A Exposure 계약에 연결한다.
- Agent Card, auth reference, task lifecycle, timeout, audit와 local smoke 항목을 설계한다.
- protocol 노출을 Agent 자산의 connection surface로 표현한다.
- 제공된 card는 합성 예시로만 취급하고 production readiness를 주장하지 않는다.
