# Expected Structure and Behavior

- canonical discovery skill을 직접 읽고 후보와 Missing Information을 설명한다.
- canonical procedure를 한 번만 실행한다.
- explicit read-only 요청에 따라 artifact를 생성하지 않는다.
- retired skill directory가 없음을 deterministic verification으로 증명한다.
- 적용한 read-only boundary와 canonical skill path를 evidence에 기록한다.
